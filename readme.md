# 🇲🇲 Myanmar Language Learning Platform API

## Introduction

This project is a Myanmar language learning website built using the AdonisJS framework. It aims to provide users with a structured platform offering lessons, exercises and audio pronunciations.

---

### ⚙️ Technologies Used

- **Backend** **Framework**: AdonisJS (Node.js)
- **Database**: PostgreSQL
- **ORM**: Lucid ORM
- **Language**: TypeScript

---

### ✨ Key Features

- **User Authentication**: System for registration, login, and tracking learning progress.
- **Interactive Exercises**: Exercises focusing on vocabulary, grammar, and reading comprehension
- **Audio Support**: High-quality audio files recorded by native speakers for accurate pronunciation.
